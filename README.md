# Directional Modulation Research Hub

Public academic knowledge hub for Directional Modulation (DM), physical-layer security, RIS, near-field communications, reconfigurable antennas, and ISAC.

## Website
After GitHub Pages is enabled, the public site URL is:
https://limaolin0302-ai.github.io/Directional-modulation/

## Literature search
- OpenAlex and Crossref: live public bibliographic metadata search inside the website.
- IEEE Xplore, Web of Science, Google Scholar, Semantic Scholar, Scopus, and arXiv: direct query links to each provider's own search page.
- Publisher full text remains subject to each provider's access policy and institutional subscriptions.
- API keys are not embedded in this public static site.

## Local preview
Open `index.html` in a modern browser. No build tools or package installation are required.

## Deployment
The GitHub Actions workflow at `.github/workflows/pages.yml` deploys the repository root whenever changes are pushed to `main`.

In the repository, open **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**, and wait for the workflow to finish. The site will then be available at the URL above.
